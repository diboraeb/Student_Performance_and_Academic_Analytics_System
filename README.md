# Student_Performance_and_Academic_Analytics_System
Many educational institutions still rely on manual records or basic systems to manage student academic performance. While these methods make it possible to store grades and student information, they often create problems such as difficulty tracking progress over time, lack of performance analysis, and inefficient record management. These issues can make it harder for instructors to identify struggling students, evaluate academic trends, and make informed decisions.
This Student Performance and Academic Analytics System is built in C++. The program is reliable, easy to use, and capable of not only storing academic data but also analyzing it to provide meaningful insights. The system uses a menu-driven interface, allowing users to navigate through different features without requiring advanced technical skills.
